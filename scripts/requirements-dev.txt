# Purpose: code, git, unit tests, wiring code that does not require MuJoCo to

# `mujoco` is still listed and pinned below -- the *package* installs fine
# and its metadata is readable (see scripts/verify_env.py), it just cannot be

# Every version below is pinned to what is actually installed and verified on
# this laptop as of 2026-09-11 (`pip freeze`), not a guess.
#
# torch is CPU-only and was installed from the PyTorch CPU wheel index:
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
# A plain `pip install -r scripts/requirements-dev.txt` will fail to resolve
# the local `+cpu` version segment for torch unless that extra index is also
# passed, e.g.:
#   pip install -r scripts/requirements-dev.txt --extra-index-url https://download.pytorch.org/whl/cpu

# openvino is needed on the LAPTOP, not only on bm-ptl: M03 converts a live
# torch.nn.Module to IR with openvino.convert_model(), which requires torch and
# openvino in the same process. Pinned to the same version as
# scripts/requirements-bmptl.txt so laptop and bm-ptl do not drift.
